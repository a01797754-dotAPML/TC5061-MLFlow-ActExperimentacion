\# Experimentación con MLflow - Car Evaluation



Proyecto correspondiente a la actividad de experimentación y seguimiento

de modelos con MLflow del curso TC5061.



\## Dataset



Se utiliza el dataset Car Evaluation para desarrollar un problema de

clasificación multiclase.



La variable objetivo es `class`, con las categorías:



\- unacc

\- acc

\- good

\- vgood



\## Modelo



Se utiliza Logistic Regression junto con OneHotEncoder para procesar

las variables categóricas.
